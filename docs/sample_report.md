# รายงานผลตรวจพื้น (ฉากจำลอง: warehouse)

**คำตัดสิน: BLOCK** — พบจุดที่ผ่านไม่ได้ 1 จุด — ต้องซ่อมพื้นหรือกำหนดเส้นทางเลี่ยง ก่อนปล่อยหุ่นวิ่งบริเวณนี้

## 1. เงื่อนไขการวัด

| รายการ | ค่า |
|---|---|
| กล้อง | Intel RealSense D455 (stereo depth) |
| ความสูงกล้องเหนือพื้น | 0.598 m |
| พื้นที่ที่สำรวจได้ | 1.68 m² (1.69 m × 2.70 m) |
| ความละเอียดกริด | 10 mm/เซลล์ |
| ความครอบคลุมข้อมูล | 36.8 % |
| ความแบนของ fit ระนาบ (RMS) | 1.78 mm |
| **ความผิดปกติที่เล็กสุดที่ยืนยันได้** | **2.86 mm** |
| หมายเหตุ | วัดจากเฟรมเดียว |

> "ความผิดปกติที่เล็กสุดที่ยืนยันได้" คำนวณจาก noise ที่วัดได้จริงในเฟรมนี้ (4σ) — ความผิดปกติที่เล็กกว่านี้อาจมีอยู่จริงแต่แยกจาก noise ไม่ได้ ถ้าต้องการละเอียดกว่านี้ ให้จอดนิ่งแล้วใช้โหมดสแกนสะสมหลายเฟรม
